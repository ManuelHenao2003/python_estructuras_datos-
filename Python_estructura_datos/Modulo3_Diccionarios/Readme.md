En este tema de diccionarios y dictionary comprehensions entendí que Python no solo permite almacenar información, sino también transformarla de manera muy eficiente y clara en una sola línea de código.

Aprendí a aplicar operaciones directamente sobre los valores del diccionario, como descuentos o cálculos, sin necesidad de crear ciclos largos. Esto me mostró que las comprensiones no son solo una forma más corta de escribir, sino una manera más expresiva de trabajar con datos.

También comprendí cómo filtrar información de forma inteligente, por ejemplo, seleccionando solo los productos disponibles o los que cumplen una condición específica. Esto me ayudó a ver que los diccionarios pueden adaptarse fácilmente a diferentes necesidades sin tener que crear estructuras nuevas.

Otro punto importante fue la transformación de datos, como invertir claves y valores, lo cual me hizo entender mejor cómo se puede reorganizar la información según lo que necesite el problema.

Además, el cálculo de porcentajes y totales me ayudó a ver cómo los diccionarios pueden ser usados en análisis de datos reales, no solo como estructuras básicas, sino como herramientas para interpretar información
