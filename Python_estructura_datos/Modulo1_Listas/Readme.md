En este proceso aprendí cómo trabajar de manera mucho más sólida con estructuras de datos en Python y a entender realmente lo que pasa “por debajo” cuando manipulo listas, diccionarios y conjuntos.

Al inicio, veía las listas solo como contenedores de datos, pero ahora entiendo que puedo acceder a sus elementos de muchas formas: por índice, con slicing, y también modificarlas con métodos como append, insert, extend, remove y pop. También aprendí que no todos los métodos funcionan igual, por ejemplo append y extend pueden parecer similares, pero uno agrega un solo elemento (incluso una lista dentro de otra) y el otro expande la lista elemento por elemento.

Otro punto importante fue entender cómo recorrer datos de forma más eficiente usando for, enumerate y zip, lo cual me permite trabajar con más de una lista al mismo tiempo o tener control de índices sin complicarme. Además, las list comprehensions me ayudaron a escribir código más corto y claro para filtrar y transformar datos.

También aprendí conceptos clave como el ordenamiento con sort y sorted, entendiendo que uno modifica la lista original y el otro no. Esto me ayudó a ver la diferencia entre trabajar con datos mutables e inmutables.

Algo muy importante fue entender el problema de las referencias en memoria. Antes no entendía por qué al cambiar una lista, otra también cambiaba, pero ahora sé que es porque ambas apuntan al mismo espacio. Gracias a copy() y deepcopy(), aprendí cómo evitar esos errores cuando necesito trabajar con copias independientes.

Finalmente, con sets y diccionarios entendí cómo manejar datos únicos, hacer operaciones como unión, intersección y diferencia, y también cómo generar reportes más avanzados usando comprensiones y funciones como sum(), max() y sorted().

En general, siento que ahora no solo escribo código, sino que entiendo mejor cómo se organizan y manipulan los datos, lo cual me da una base mucho más fuerte para resolver problemas más complejos en programación
