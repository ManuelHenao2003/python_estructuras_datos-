lo que trabajé con tuplas me ayudó a entender una parte muy importante de Python: la inmutabilidad y cómo se organiza la información de forma segura y estructurada.

Aprendí que una tupla es similar a una lista, pero con la diferencia de que no se puede modificar después de creada. Esto me hizo entender por qué se usan en casos donde los datos deben permanecer constantes, como coordenadas, configuraciones o registros que no deben cambiar. También vi que, aunque la tupla no se puede modificar, sí permite acceder a sus elementos mediante índices, slicing y operaciones como count e index.

Otro punto clave fue el desempaquetado de tuplas, que me permitió extraer valores directamente en variables, lo cual hace el código más limpio y fácil de leer. Además, aprendí técnicas más avanzadas como el uso de *resto para capturar múltiples valores y el intercambio de variables en una sola línea sin necesidad de variables temporales.

También entendí algo muy importante: las tuplas pueden contener elementos mutables dentro de ellas, lo que significa que aunque la estructura principal sea inmutable, su contenido interno puede cambiar si es mutable, como listas dentro de una tupla.

Finalmente, comprendí cómo las tuplas funcionan en estructuras más avanzadas como diccionarios, donde pueden ser usadas como claves debido a su inmutabilidad, a diferencia de las listas que no son válidas por ser mutables.
